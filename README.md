# Material Emprestado

Plataforma para gestão de empréstimo de materiais com foco em experiência, visibilidade e automação.

## Estrutura

- `frontend/`: aplicação React (Vite) com UX otimizado.
- `api/`: API em Node/Express para fornecer os dados de materiais.

## Como rodar localmente

### 1) API

```bash
cd api
npm install
npm run dev
```

A API ficará disponível em `http://localhost:4000/api/materials`.

### 2) Front-end

```bash
cd frontend
npm install
npm run dev
```

A aplicação ficará disponível em `http://localhost:4173`.
